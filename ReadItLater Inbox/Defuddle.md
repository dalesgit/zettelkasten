# [Defuddle](https://stephango.com/defuddle)

## 2025

> de·​fud·dle /diˈfʌdl/ *transitive verb*
> 
> to remove unnecessary elements from a web page, and make it easily readable.

Inspired by my work on [Obsidian Web Clipper](https://stephango.com/obsidian-web-clipper) I created [Defuddle](https://defuddle.md/), an open source library that extracts the main content from any HTML or web page, and converts it to Markdown.

The simplest way to use it is to add `defuddle.md` before any URL, which will return Markdown.

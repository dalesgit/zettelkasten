I’ve used just about every “read-it-later” app out there, and none of them stuck. To my surprise, what finally worked wasn’t a read-it-later app at all. It was Obsidian.

## Why do I now use Obsidian for saving web pages?

The problem isn’t the read-it-later apps themselves, but it’s the tool separation. For me, my daily notes app is where I capture my thoughts and just about everything else. Obsidian is the app I open every day, and jot down all my thoughts and ideas into.

When I save web pages in another app, this fragments the process. Reading becomes a separate task that demands conscious effort, rather than flowing naturally into my daily workflow, because I usually want to highlight, or even jot down things while I am reading. As a result, my saved content used to be somewhere and my notes elsewhere.

Finally, with a few tweaks, I’ve made Obsidian my read-it-later hub. And now, I am not just saving articles, but actually reading them. As a result, my backlog is under control, and my curiosity is satisfied.

So, how do I save web pages in Obsidian?

## 1\. The official Obsidian Web Clipper

![Obsidian official web page showing web clipper](https://static0.howtogeekimages.com/wordpress/wp-content/uploads/2026/01/obsidian-web-page-showing-web-clipper.png?q=49&fit=crop&w=825&dpr=2)

By default, Obsidian is a [Markdown](https://www.howtogeek.com/obsidian-is-the-best-markdown-note-taking-app-youve-never-heard-of/) note-taking app. It doesn’t come with web-clipping features out of the box. But with a bit of tweaking, you can quickly turn Obsidian into a powerful tool for saving web pages. The first way to do this is by using the official browser extension from Obsidian.

The extension saves clean text directly into a Markdown file in your vault. And it’s very easy to set up and use. Seriously! It’s like two clicks and you’re done.

To set up the [Obsidian Web Clipper](https://obsidian.md/clipper):

1. Head over to the Chrome Web Store, or the extension store of your preferred browser.
2. Search for Obsidian Web Clipper.
3. Download the extension.

![Using Obsidian web clipper to save a web page](https://static0.howtogeekimages.com/wordpress/wp-content/uploads/2026/01/using-obsidian-web-clipper-to-save-a-web-page.png?q=49&fit=crop&w=825&dpr=2)

Now, to save a web page:

1. Open the page you like (for me, it’s often something tech-related).
2. Click the Obsidian icon in your browser toolbar.
3. The page is saved in your vault.

![saved webpage opened in Obsidian](https://static0.howtogeekimages.com/wordpress/wp-content/uploads/2026/01/saved-webpage-opened-in-obsidian.png?q=49&fit=crop&w=825&dpr=2)

That’s it. No fuss, no headaches. Just quick and easy, which is perfect when you’re in a hurry.

## 2\. The ReadItLater Plugin

The second method I use is an Obsidian community plugin called [ReadItLater](https://github.com/DominikPieper/obsidian-ReadItLater). This one is especially good if you use Obsidian frequently on your phone, because it works really well with the smartphone version of Obsidian.

![ReadItLater Obsidian plugin download page](https://static0.howtogeekimages.com/wordpress/wp-content/uploads/2026/01/readitlater-obsidian-plugin-download-page.png?q=70&fit=crop&w=825&dpr=1)

To set up the ReadItLater plugin:

1. Go to Community Plugins in Obsidian settings.
2. Search for ReadItLater, download it, and enable it.
3. Open the web page you want to save and copy the URL.
4. Go back to Obsidian, hover over the toolbar icon labeled ReadItLater, and click it.

## 3\. The SingleFile Browser Extension

![SingleFile browser extension opened in Chrome](https://static0.howtogeekimages.com/wordpress/wp-content/uploads/2026/01/singlefile-browser-extension-opened-in-chrome.png?q=49&fit=crop&w=825&dpr=2)

Web pages are complex. Not all pages behave the same way. Some use lazy loading, some rely heavily on JavaScript, and there’s often a lot going on under the hood. To cover every possibility and be able to save any web page, I use multiple tools. If one doesn’t work, the other usually will.

The SingleFile extension is quite different from the options above. It takes an entire web page and saves it as a single HTML file, including images and styling.

You end up with one self-contained HTML file. No messy image folders, just one neat package.

This is something I absolutely love. I don’t have to deal with image folders, and more importantly, the layout and formatting of the original page are preserved. Font styles and sizes carry over. It feels like you’re opening the original web page, not reading a plain Markdown file.

![HTML webpage opened in Chrome](https://static0.howtogeekimages.com/wordpress/wp-content/uploads/2026/01/html-webpage-opened-in-chrome.png?q=70&fit=crop&w=825&dpr=1)

I use this extensively for two main reasons:

- When I like the theme and style of a web page and want to preserve the original reading experience.
- When saving content from dynamic websites like ChatGPT. No matter how long the conversation is, it gets packaged perfectly.

## What is Drawpile?

### A collaborative art app that doubles as a photo editor

   ![Drawpile onboarding screen](https://static0.xdaimages.com/wordpress/wp-content/uploads/wm/2025/12/drawpile-onboarding-screen.png?q=49&fit=crop&w=825&dpr=2)

Drawpile is a completely open-source and [free raster graphics app](https://www.xda-developers.com/free-graphics-app-never-pay-for-adobe-again/). It is technically an art app, though that description doesn’t really cover the full extent of what it’s capable of. Most people try it for the collaborative canvas since multiple users can draw and paint on the same file in real time, kind of like a shared whiteboard but more artistic. Underneath that selling point is a perfectly capable graphics editor that works well for different kinds of solo projects too, including photo editing.

It’s available on Windows (including ARM), macOS, Linux, and Android (on F-Droid). Furthermore, it has a portable version as well as a web version, and it also lets you draw with a stylus, complete with pressure sensitivity. If I can use a creative app on my little Chromebook, I consider it accessible, and Drawpile works perfectly fine on it via both Linux and web.

Drawpile is ideal for anyone who wants a lightweight and free editing and drawing space, whether as a solo creator or part of a team. It’s actually a great way for teams to test-run projects before paying for studio-grade collaborative tools. Though it’s perfectly capable of handling more advanced projects on its own, too.

## What Drawpile has to offer

### It holds up quite well against Adobe’s graphic tools

The first thing I noticed about Drawpile was all the paintbrushes in the left panel. Granted, it is primarily a drawing app, but Photoshop’s default collection still pales in comparison. Using brushes artistically isn’t my main focus, but I did test them out and the feel is quite similar to Krita; it’s very smooth, but smoothness and all the other properties are adjustable. What I like these brushes for most is the ability to paint textures and colors onto my images. It also comes with dedicated burn & dodge tools, but unfortunately, there are no dedicated HSL sliders, so you’ll have to make do with the coloring options and blending modes.

As for the selection tools; it’s not on par with Photoshop's advanced offerings. However, it’s decent enough for more casual users who just want to manipulate everyday pictures. You’ve got the rectangle and ellipse select, and then you’ve also got a Lasso tool. The latter is quite accurate for detailed selections. There’s also a Magic Wand tool for quick selections. You can create clipping masks and fill layers using these selection tools, and every layer comes with custom adjustable properties.

The rest of the tools I consider extras since they’re not entirely necessary for the work I do, such as the Gradient tool, Text tools, and Bezier tool. Just like in Photoshop, you can also create basic animations, which is quite impressive. And you’ve got some basic transform controls like cropping and rotating. Drawpile actually lets you import, edit, and export PSD files. It also supports JPEG, PNG, WebP - all the basics - plus OpenRaster, which you can import into Krita, too. A really cool feature I like is Record, which basically just takes a screen recording of your and your team’s work that you can watch back later.

## Where Drawpile falls short

### Don’t expect it to be a complete Photoshop or Illustrator replacement

   ![Blending brush and color layers in Drawpile](https://static0.xdaimages.com/wordpress/wp-content/uploads/wm/2025/12/blending-brush-and-color-layers-in-drawpile.png?q=49&fit=crop&w=825&dpr=2)

As I’ve mentioned, Drawpile doesn’t have HSL sliders or photo filters, so you’ll have to get creative with the layers, color options, brushes, and blend modes. Being a raster editor, it’s also not going to let you edit vector files. The selection tools aren’t quite as fleshed out as Adobe’s offerings. And there’s no version history, which means it’s not a non-destructive editor, so you’ll have to rely on the undo function to roll back to specific changes. This also means no Smart Objects.

### A decent editor all-in-all

Drawpile is far more capable than I expected it to be for a free and old drawing app. I don’t mind that it's not quite as advanced or polished as Adobe. It strikes a nice balance between accessibility and power, which makes it perfect for those who want an [open-source Adobe alternative](https://www.xda-developers.com/should-have-left-adobe-for-open-source-graphics-stack-sooner/) that can run on modest hardware for casual drawing and editing. I think it’s worth giving this a proper shot before paying for a subscription.
